# RedAR

**Una red inteligente para encontrar ayuda.**

RedAR es una plataforma open source para encontrar recursos, servicios y espacios de ayuda en Argentina, empezando por CABA.

## Objetivo

Convertir una necesidad concreta en opciones accionables: qué recurso existe, dónde está, quién puede acceder, qué requisitos tiene y qué hacer a continuación.

## Categorías iniciales

- Alimentación
- Educación
- Empleo
- Salud
- Vivienda
- Discapacidad y accesibilidad
- Documentación y trámites
- Tecnología
- Asesoramiento
- Actividades gratuitas

## Principios

- **Acción antes que listado:** cada resultado debe indicar qué hacer ahora.
- **Accesibilidad:** interfaz clara, navegación por teclado y lenguaje sencillo.
- **Privacidad:** no pedir datos personales innecesarios.
- **Verificación:** los recursos tendrán estado de verificación y fecha de actualización.
- **Bajo consumo:** debe funcionar razonablemente bien con conexiones lentas.
- **Open source:** código y documentación abiertos.

## Roadmap

1. MVP web responsive.
2. Buscador de recursos.
3. Filtros por categoría, ubicación y accesibilidad.
4. Mapa interactivo.
5. Fichas de recursos con verificación.
6. Flujo «¿Qué hago ahora?».
7. Panel para actualizar recursos.
8. Expansión desde CABA al resto de Argentina.
